Overview

What is ARC?

ARC (Analysis and Research Compendium) is a comprehensive library of harmonised questions designed to rapidly build standardised Case Report Forms (CRFs) for disease outbreaks. It covers a wide range of patient-related information, including demographics, comorbidities, signs and symptoms, medications, outcomes, and more.

Each question in ARC has specific guidelines and relevant parameters, such as definitions, answer options, units, minimum and maximum limits, data types, and skip logic.

Key Features

✓
Machine-Readable

ARC is provided in CSV format, making it easy for automated systems to read and process the data.

✓
Open Access

Freely accessible for the research community. While contributions are limited, the document can be freely accessed and utilized by others.

✓
Version Control

Maintained using GitHub's version control, ensuring document integrity, traceability of changes, and seamless collaboration.

✓
Integration with BRIDGE

ARC is integrated into BRIDGE, our software tool for CRF generation.

ARC Components

arc.csv

The machine-readable list of clinical and research questions. Each row represents a variable used in the CRFs, including metadata that ensures clarity, interoperability, and reusability across contexts.

Lists/

A collection of option lists containing standardised reference tables (conditions, demographics, and drugs) that support different response types while ensuring adaptability and consistency in data capture.

Data Capture Schema

The ARC data structure follows the Clinical Characterization data capture schema, defining key moments during a patient's journey:

Illness onset → onset-to-care information
Presentation → data when patient first presents to care
Daily observation → repeated measurements throughout admission
Outcome → information at discharge or death
Follow-up → post-discharge information
Summary → aggregate data spanning full admission

How to

Understanding arc.csv Structure

Each row in arc.csv represents a variable with the following key fields:

Field Description Example Value
Form CRF form where the variable appears Presentation
Section Subdivision within the form that groups related questions CO-MORBIDITIES AND RISK FACTORS: Existing prior to this current illness and is ongoing
Variable Unique identifier used in the dataset comor_hypertensi
Type Format of the response field radio
Question Human-readable text shown to the data collector Hypertension
Answer Options Permissible responses to the question 1, Yes | 0, No | 99, Unknown
Body System Physiological system the variable belongs to Cardiovascular
Definition Description of the concept being captured Defined as elevated arterial blood pressure diagnosed clinically (systolic >140 mmHg and/or diastolic >90 mmHg), or treated with medication.
Completion Guideline Instruction text for data collectors to standardize responses Indicate 'Yes' if this condition existed prior to admission with this current illness and remains an active medical condition.
Standardized Term Codelist Reference ontology or terminology system used for harmonization SNOMED
Standardized Term Code The specific code(s) from the ontology 38341003, Hypertensive disorder, systemic arterial (disorder)
Metathesaurus Identifier UMLS Metathesaurus identifier for cross-referencing C0020538, Hypertensive disease
Research Category Category for research classification risk_factor_comor
Presets (selected) Links to where the variable is used in disease-specific CRFs COVID=1, Dengue=1, Mpox=1, H5Nx=1, ARI=1

Example row: The variable comor_hypertensi captures hypertension information in the Presentation form, with answer options Yes/No/Unknown, mapped to SNOMED CT code 38341003.

Version Identification

ARC uses a version numbering system to indicate different levels of updates:

  • Major Version: Significant updates including new events, forms, or diseases
  • Minor Version: Smaller updates, new features, or modifications to questions
  • Patch Version: Bug fixes, writing improvements, or small corrections

Previous ARC versions can be accessed via the repository's releases section. Additional questions can be added to future ARC versions by contacting data@isaric.org.
