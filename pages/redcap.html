Overview

Important: REDCap is developed and maintained by Vanderbilt University. It is not an ISARIC tool but integrates seamlessly with the ISARIC analytical framework.

Integration with ISARIC Tools

REDCap plays a key role in the ISARIC ecosystem:

🔗
BRIDGE Integration

BRIDGE generates the data dictionary and XML needed to create a REDCap database for capturing data in the ARC structure.

📊
VERTEX Integration

VERTEX can retrieve data from a REDCap database using the API to execute analysis code and answer research questions.

Setup & Configuration

Scope

This guide applies to databases hosted on the ISARIC instance of REDCap.

Purpose

The purpose of this guide is to ensure:

  • that the database is accessed only by delegated study staff
  • that study staff are familiar with the functioning of the study database
  • that data in the database is secure

Responsibility

The principal investigator is responsible to determine who has access to the study database. Study staff are responsible for protecting their access credentials, entering data to the database, and ensuring the accuracy of the data entered.

Request for Access to a Database

Approval

Access to a REDCap database must be approved by the Site Principal Investigator (PI) or an individual delegated by the PI.

Individual Account

Access is granted to individual staff members. Accounts cannot be shared, and passwords must be kept secure.

Request

To request access to a REDCap database, an email must be sent by the site PI or their delegate to the Central Coordinating Office (CCO) at data@isaric.org.

The request must include:

  • The name of the database
  • The first and last name of the individual
  • Their email address
  • Their data entry role
  • The name of the site the individual should be assigned, if relevant

Credentials

Once access is granted, the new user will receive:

  • An automatic email from REDCap containing a username, a temporary password, and the link to access the database
  • An email from the CCO including their site code

Upon first login, users will be prompted to set a new, secure password.

Logging into ISARIC REDCap

Go to https://ncov.medsci.ox.ac.uk - the link will be in the email you are sent.

Data Sharing Guidance

If you have collected data on your own instance of REDCap and wish to share it on the ISARIC Platform, please follow the steps below.

STEP 1: Signing Terms of Data Submission

Ensure that Terms of Data Submission are in place before proceeding.

STEP 2: Sharing the Data Dictionary

Share the data dictionary of your REDCap Project.

If you used BRIDGE to build your CRF, it will be really useful if you can also share with us any change in name of the variable, name on the label or choices of answers. This impacts the mapping of the data to integrate them in our data platform, and it will be easier with those changes clearly identified.

How to Download the Data Dictionary?

On the menu click on "Dictionary" then click on "Download the current Data Dictionary".

REDCap - Download Data Dictionary

STEP 3: Sharing the Data

There are two options for sharing the data with us: either by providing access to your API or by securely sharing the data in a CSV file.

OPTION 1: Providing Access to Your API

We can access your data directly through the REDCap API. To do this, you will need to:

  1. Add the ISARIC data manager as a user on your REDCap instance
  2. Grant them access to your database
  3. Generate an API token for them to enable access
1. Add the ISARIC data manager as a new user on your REDCap instance

Click on "Control Center".

REDCap - Add User

Click on "Add Users (Table-based Only)".

REDCap - Add Users

Complete the information and click on "Save" at the bottom of the page. The user account will be created.

REDCap - Complete User Info

2. Grant them access to your database

REDCap - Grant Access

REDCap - Access Privileges

Click on "Add user". The ISARIC Data Manager will be notified that they now have access to the database. They will access the REDCap project and request an API token and send you a message to inform you the request has been made.

3. Generate an API token for them to enable access

The API token request from the ISARIC Data Manager will appear in the Control Center "To-Do List". If you do not have Administrator rights, please ask your administrator to approve this request.

Click on To-Do List.

REDCap - To-Do List

Click on the green tick to approve the request.

REDCap - Approve Request

The ISARIC Data Manager can now export directly from your database the data.

OPTION 2: Securely Sharing a CSV File

1. Download the data in CSV

In the REDCap side bar, click on "Data Exports, Reports and Stats" then on "Export Data".

REDCap - Export Data

Choose "CSV/Microsoft Excel (raw data)" then "Export Data". A pop-up window appears; click on the icon to download the data.

REDCap - Download CSV

2. Send securely the data

Do not send your data by email – it is not secure. REDCap has an integrated secure tool for sending data.

Click on the Welcome page of REDCap on "Send-It".

REDCap - Send-It

Complete the address of the ISARIC Data Manager, email subject, and select your CSV file, then click on "Send it".

REDCap - Send File

If your file is larger than the max file size of 128MB, please contact us at data@isaric.org.
